# Карфаген — новинний сюжет

Фінал: 03:56 · 1080×1920 · 30 fps · H.264 Baseline / AAC. Вісім авторських пояснень чергуються із сімома оригінальними заявами. Авторського голосу та музики немає. Під час майбутнього авторського тексту тиша; оригінальні репліки збережені.

## Редагування

`npm ci`, потім `npm run studio`. Studio: http://localhost:3002, композиція KarfagenNews.

Окремі послідовності: відеоряд, оригінальні репліки, VOICEOVER, субтитри та короткі інформаційні акценти. `editorial/timeline.json` містить усі часові вікна й посилання на підготовлені кліпи.

Замініть `public/audio/VOICEOVER.wav` власним стереозаписом 48 kHz тривалістю 236 секунд від 00:00, з тишею під оригінальними заявами. Текст і паузи: `editorial/VOICEOVER.txt`; репліки джерела: `editorial/ORIGINAL_SYNCHS.txt`. Remotion читає голос тільки в авторських вікнах. Для рендеру Remotion: `npm run render`. Для відтворення компактного фіналу через FFmpeg: `python render_ffmpeg.py`.

Підготовлені кліпи вже мають нормальну швидкість; не сповільнюйте їх повторно. Два вихідні записи екрана не включені до архіву через обсяг. Нативну якість із них не відновлено. Повні машинні транскрипти — чернетки з помилками; перевірені обрані цитати відокремлені у ORIGINAL_SYNCHS.txt.

Фактологія й джерела: `editorial/REPORT.md`. Перевірки: `editorial/QA.json`, `editorial/FINAL_TECHNICAL_CHECK.json`. Субтитри: `editorial/ALL_SUBTITLES.srt`. DejaVu ліцензія включена.
