- `AZOV-MUSIC.m4a` — інструментальна музика окремо.

## Як додати голос

Імпортуйте відео без музики та `audio/MUSIC.wav` у редактор. За потреби замість звуку MP4 використайте `audio/ORIGINAL.wav` — він починається з 00:00 і вже містить паузи між сімома заявами. `audio/VOICEOVER.wav` — повністю порожня доріжка тієї самої довжини, для заміни вашим записом. Слова й інтервали: `AZOV_VOICEOVER.txt`. Місця оригінальних голосів: `AZOV_ORIGINAL_SOUND.txt`. Не накладайте авторський голос на ці інтервали.

## Редагування і повторний рендер

Проєкт використовує FFmpeg, а не закритий формат монтажної програми. У пакеті є всі вже підготовлені відеофрагменти; оригінальні новинні програми цілком не перепубліковуються.

Потрібні Python 3 та FFmpeg із libx264, AAC і libass. Із каталогу розпакованого проєкту:

```sh
python render_final.py
python render_final.py --without-music
```

`timeline.json` описує кадри, джерельні таймкоди, авторські та оригінальні звукові інтервали. `AZOV_TITLES.ass` — редаговані титри; `AZOV_SUBTITLES.srt` — субтитри. Для зміни тексту й автоматичного переформування титрів: відредагуйте текст сцен у `timeline.json`, установіть Pillow та запустіть `python captions.py`, а потім повторний рендер. Змінюючи тривалість сцен, потрібно узгодити кадри й аудіо: саме переписування JSON не розтягує готові кліпи автоматично.

`render_segments.py` та `audio.py` збережено як вихідні монтажні скрипти. Для повторного виділення уривків із довших джерел потрібні вихідні записи, перелічені в `AZOV_MEDIA.csv`; вони збережені в робочій папці, а джерела наведені в звіті. Для звичайного рендеру готового проєкту ці довгі оригінали не потрібні.

Опрацьовано всі 71 сторінку наданого PDF. Основний фільм охоплює 2014–2022 роки; короткий епілог показує подальшу історію. Не кожне твердження презентації вдалося незалежно підтвердити. Такі епізоди прямо атрибутовані джерелу; дев’ять недатованих записів журналу позначено як передрук. Відсутні первинні матеріали не підмінені випадковими боями чи реконструкціями. Стан незалежної перевірки наведено в `AZOV_RESEARCH.md` і `AZOV_MISSING_MATERIALS.md`.
