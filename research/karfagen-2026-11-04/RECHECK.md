# Повторна перевірка оригінального посилання

5 листопада 2026 року, близько 08:13 UTC.

- Коротке посилання користувача: https://youtu.be/dLGhaHbWCAA?si=ayxBwz-QFNEVwpdX — HTTP 403 від проксі при CONNECT до youtu.be:443, curl exit 56.
- Канонічне посилання: https://www.youtube.com/watch?v=dLGhaHbWCAA — HTTP 403 від проксі при CONNECT до www.youtube.com:443, curl exit 56.
- Відмову отримано до TLS із сервером YouTube. Цей результат не встановлює, чи доступне відео для звичайного глядача, чи воно приватне, видалене або має вікові обмеження.
- Конфігурація керованого середовища: revision 4, observed revision 4, observations_current=true, running, connected, HTTP policy unrestricted/enforced. Незастосована чернетка або відсутність мережі цим статусом не підтверджуються. Unrestricted не вимикає захисні обмеження платформи.
- Дві офіційні сторінки НАБУ: HTTP 200. Обидві містять iframe https://www.youtube.com/embed/dLGhaHbWCAA; окремий повний відеофайл у доступній розмітці не знайдено.
- Офіційні Telegram-публікації НАБУ/4261 та САП/4472: HTTP 200, посилання на те саме YouTube-відео; в доступній веброзмітці немає власного video/source із повним записом.
- https://nabu.gov.ua/video/ — HTTP 404. Це лише перевірений шлях, не твердження, що на сайті взагалі немає інших відеорозділів.
- https://www.sap.gov.ua/ — HTTP 403. Його причину не прирівнюємо автоматично до діагнозу YouTube.

Попередньо перевірені новинні публікації та відкриті Telegram-канали дали короткі уривки, перелічені в REPORT.md, а не повний запис. Локальна транскрипція уривків не замінює повний аналіз фільму. Повного відео, повних субтитрів та перевірених таймкодів усього оригіналу немає.

Проксі, VPN, альтернативні IP, неофіційні сервіси витягування відео та обхід авторизації не використовувалися. Розпізнавання медіа або зміна формату посилання не усувають відмову CONNECT; видавати це за проблему кодека чи прав доступу до конкретного ролика було б неточно.
