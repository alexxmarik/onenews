# «Карфаген»: новинний Reels, 04.11.2026

Монтаж 04:12, 1080×1920, 30 fps. Основний MP4 експортовано FFmpeg. Редагований Remotion-проєкт відтворює ті самі відеофрагменти, синхрони, авторські вікна й текстові шари. TypeScript перевірено; кадр Remotion відрендерено через Chromium.

## Що містить відео

- Тільки відеоряд із двох наданих записів офіційного фільму НАБУ/САП, адаптований до вертикального формату. Ділянки джерела не повторюються.
- Чотири синхрони з оригінальним звуком. Це коментарі детектива у фільмі, а не зізнання фігурантів.
- Тихі ділянки для майбутнього авторського голосу. Це навмисні паузи, не помилка експорту.
- Текстові акценти, субтитри синхронів і переказ письмової реакції СБУ.
- Музики, AI-голосу, реконструкцій і стороннього стокового відео немає.

## Додати свій голос

1. Прочитайте `editorial/VOICEOVER.txt`: це повний авторський текст із часовими вікнами. Оригінальні синхрони позначені паузами.
2. Підготуйте запис завдовжки **252 секунди від 00:00**, з тишею на місцях синхронів.
3. Замініть `public/audio/VOICEOVER.wav` своїм WAV, залишивши назву. Наявний файл повністю порожній, 48 kHz, stereo.
4. Запустіть Remotion і перевірте синхронізацію. Вікна VOICEOVER уже розділені на окремі JSX-послідовності; голос не відтворюється під час синхронів.

У CapCut можна імпортувати готовий MP4 та накласти власний запис на окрему звукову доріжку за цими таймкодами. Додатковий порожній аудіопотік MP4 деякі редактори не показують як монтажну доріжку — для редагування використовуйте WAV або проєкт Remotion. Оригінальний звук також є у `public/audio/ORIGINAL.wav` і чотирьох окремих файлах `original-*.wav`.

## Запуск Remotion

```sh
npm ci
npm run studio
```

Після запуску Studio: http://localhost:3000.

Рендер із Remotion:

```sh
npx remotion render src/index.ts Karfagen out/karfagen-remotion.mp4 --codec=h264 --crf=23
```

Якщо Chromium уже встановлено, можна додати `--browser-executable=/usr/bin/chromium`. У керованому середовищі з Node 24 для налаштованого HTTP-проксі може бути потрібне `NODE_USE_ENV_PROXY=1`. Не вимикайте перевірку TLS і не обходьте мережеві обмеження.

Повторний FFmpeg-експорт:

```sh
python3 render_ffmpeg.py
```

Цей експортер створює основний потік PROGRAM із синхронами та майбутньою озвучкою, а також зберігає окремі потоки ORIGINAL і VOICEOVER. У наданому первинному MP4 містяться ORIGINAL та порожній VOICEOVER; жодного авторського голосу ще немає.

## Організація

- `src/Root.tsx` — 39 окремих відеопослідовностей, синхрони з прив’язаними субтитрами, сім авторських вікон і незалежні текстові акценти.
- `editorial/timeline.json` — монтажна карта та відповідність вихідним записам.
- `editorial/ORIGINAL_SYNCHS.txt` — точні місця використаних синхронів у монтажі й відповідних частинах.
- `editorial/VOICEOVER.txt` — авторський текст.
- `editorial/ORIGINAL_SUBTITLES.srt` — субтитри оригінальних синхронів.
- `editorial/editorial.ass` — текстові шари FFmpeg.
- `editorial/REPORT.md` — журналістський розбір і джерела.
- `editorial/source-transcripts/` — повні **машинні чернетки** розпізнавання, які не є вичитаною стенограмою. Не використовувати неперевірені слова, прізвища чи числа як готові цитати.
- `public/clips/` — усі підготовлені відеофрагменти, тому відтворення монтажу не потребує доступу до YouTube.

Час джерела зазначений локально у відповідній частині при ×1, а не як гарантований таймкод YouTube. Записи екрана приблизно 52:28 після відновлення швидкості; відсутність пропуску на стику з недоступним оригіналом не встановлена. Сирі записи сумарно понад 580 МБ до архіву проєкту не включені; наданих кліпів достатньо для додавання голосу, титрів та редагування наявних сцен. Для подовження вихідної ділянки потрібен відповідний запис екрана.

Деталізація зображення обмежена записом екрана. Експорт 1080×1920 не перетворює його на нативне Full HD.
