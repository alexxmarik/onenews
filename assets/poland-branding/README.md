# Оригінальні плашки для сюжету про Польщу

Додайте сюди два оригінальні графічні файли:

- `logo_top_right.png` — правий верхній кут.
- `logo_bottom_left.png` — лівий нижній кут.

Обидва файли можна вибрати одночасно на сторінці Upload files, потім натиснути **Commit changes**. Використовуйте вихідні PNG-файли, без генерації або зміни дизайну. Якщо плашки однакові, можна завантажити дві копії одного оригіналу із зазначеними назвами.

Чат показує прев’ю зображень, але в поточній сесії їхні бінарні оригінали не доступні монтажним інструментам. Завантаження у GitHub дозволить отримати саме ваші файли без перемальовування. Попередні AI-підготовлені логотипи не використовуються.

Сюжет підготовлено на основі наданого тексту Reuters: 2 хв 48 с, українські субтитри, фоновий інструментал, без дикторської озвучки. Експорт із плашками очікує цих оригіналів.
