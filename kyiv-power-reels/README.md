## Заміна голосу і рендер

Замініть public/audio/VOICEOVER.wav записом 48 kHz стерео, від 00:00, на повну тривалість 69,6 с. Фінальний MP4 із титрами можна імпортувати в CapCut, а голос додати окремо. Для відтворення рендера через FFmpeg: python render.py. Встановіть FFmpeg із libass; Python не потребує зовнішніх бібліотек для фінального складання. Повний перебудовний скрипт підготовки використовує Pillow.

Вихідні відео і справжні скриншоти включені. У documents збережені оригінальні зображення та кадровані уривки. Коментарі відомі з публікації місцевого каналу, їхня тривалість і авторство незалежно не встановлені. Не трактуйте їх як статистику.
