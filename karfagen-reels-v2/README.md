# «Карфаген» — перероблена версія V2

04:12 · 1080×1920 · 30 fps · H.264/AAC.

## Що виправлено

- Оригінальна репліка починається від 00:00. Усього шість фрагментів із вихідним звуком — 67,3 секунди; гучність вирівняна до орієнтира −16 LUFS.
- Повний авторський коментар тепер є **субтитрами в самому відео**, а не лише в TXT. Власний коментар і оригінальні репліки мають різні позначення.
- Поля телефонного запису, інтерфейс плеєра та старі автосубтитри виключені кадруванням. Сірих розмитих смуг немає. Джерело залишається записом екрана; втрачену ним деталізацію не відновлено штучно.
- У головному MP4 один аудіопотік PROGRAM. Порожній потік не може бути помилково вибраний плеєром замість оригінального звуку.
- Озвучку автора та музику не генерували. Під час авторського коментаря звук вимкнений; текст можна прочитати на екрані.

## Редагування та голос

`public/audio/VOICEOVER.wav` — порожній WAV тривалістю 252 секунди від 00:00. Замініть його своїм записом із паузами на місцях синхронів. У Remotion авторські вікна вже розділені та не перетинаються з оригінальним звуком. Синхрони мають окремі WAV і спільні з відповідними відео та субтитрами групи.

- `editorial/VOICEOVER.txt` — повний авторський текст із часовими вікнами.
- `editorial/ORIGINAL_SYNCHS.txt` — шість оригінальних реплік, їхні місця в монтажі й у частинах джерела.
- `editorial/ALL_SUBTITLES.srt` — усі субтитри коментаря та синхронів.
- `editorial/AUTHOR_SUBTITLES.srt` — лише наш коментар.
- `editorial/ORIGINAL_SUBTITLES.srt` — лише оригінальні репліки.
- `editorial/timeline.json` — монтажна карта.
- `editorial/editorial.ass` — оформлення титрів FFmpeg.

Авторські субтитри прив’язані до запланованого темпу читання, оскільки самого голосу ще немає. Після запису можна уточнити їхню синхронізацію. Час джерела локальний у кожній частині при відновленій швидкості ×1; це не гарантований таймкод YouTube.

## Запуск

```sh
npm ci
npm run studio
```

Studio: http://localhost:3001, якщо запустити `npx remotion studio src/index.ts --port=3001`.

```sh
npx remotion render src/index.ts KarfagenV2 out/karfagen-v2.mp4 --codec=h264 --crf=21
```

На машині з готовим Chromium можна додати `--browser-executable=/usr/bin/chromium`. У керованому середовищі з Node 24 для налаштованого проксі може бути потрібне `NODE_USE_ENV_PROXY=1`.

Для повторного FFmpeg-експорту підготовлених кліпів і титрів:

```sh
python3 render_ffmpeg.py
```

Основний MP4 експортовано FFmpeg. Remotion містить окремо редаговані відео, оригінальні аудіофрагменти, майбутній VOICEOVER, повні субтитри та заголовки. Перевірені компіляція TypeScript і рендер контрольного кадру.

Повний початковий запис екрана не входить до проєкту через розмір. Усі використані підготовлені відеофрагменти включені, тому для додавання голосу доступ до YouTube не потрібний. Машинні транскрипції у `source-transcripts` — невичитані чернетки, а не готові дослівні цитати.
