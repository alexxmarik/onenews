# Універсальний новинний шаблон — 1080×1920, 30 FPS, без голосу

Шаблон для швидкого створення вертикальних новинних відео українською. Жодних вбудованих новинних фактів, звернень до сайтів, TTS або голосових генераторів немає.

## Що готово

- `out/template-preview.mp4`: 12-секундний технічний перегляд без жодної аудіодоріжки.
- `out/template-preview-music.mp4`: той самий перегляд із тихою інструментальною музикою, без голосу.
- `assets/audio/music.wav`: окремий вихідний музичний файл. Походження — `assets/audio/ORIGIN.md`.
- `content/story.json`: редагований сценарій: заголовки, тривалість сцен, фото/відео, джерела, інфографіка.
- `content/subtitles.srt`: українські субтитри з часовими інтервалами.
- `src/render.py`: монтаж і експорт H.264 MP4 через FFmpeg.
- `src/graphics.py`: анімовані великі показники, стовпчикові діаграми, GeoJSON-карти з маркерами.
- `src/add_voice_later.py`: окремий необов’язковий крок для вашого власного запису в майбутньому. Він не викликається під час звичайного експорту й нічого не синтезує.

Це універсальний шаблон, а не новинний сюжет про Польщу. Демонстраційні тексти прямо позначені як технічні заповнювачі.

## 1. Додайте власні оригінальні плашки

Очікувані шляхи:

```text
assets/branding/logo_top_right.png
assets/branding/logo_bottom_left.png
```

Перевірка після завантаження:

```sh
python src/render.py --check-assets
```

Звіт показує наявність файлів, розміри, формат та SHA-256. У цій поставці оригінальні PNG недоступні, тому в перегляді показані підписані місця, а не відтворені логотипи. Файлів підміни немає.

Плашки ніколи не обрізаються, не перемальовуються, не перефарбовуються; тло автоматично не видаляється. Повністю зберігаються вміст, прозорість і пропорції, застосовується лише пропорційне вписування в передбачений прямокутник. Оригінальні файли на диску не змінюються; після експорту перевіряється їхня SHA-256. Якщо вихідний PNG містить велике порожнє поле, воно теж збережеться — шаблон не має права його обрізати.

Позиції для всього відео, у пікселях:
- Праворуч угорі: x=652…932, y=225…285.
- Ліворуч унизу: x=64…344, y=1440…1500.

Плашки додаються останнім шаром кожного кадру і не зникають під час переходів. Заголовки, відео й субтитри мають окремі області та не перекривають логотипи. Область важливої інформації: x=64…932, y=220…1515. Елементи інтерфейсу конкретної соцмережі можуть змінюватися; перевіряйте її попередній перегляд перед публікацією.

## 2. Підставте перевірену новину

Відредагуйте `content/story.json`:
- Замініть заголовки, пояснення та тривалість сцен.
- Додайте `source` з посиланням або назвою перевіреного документа для кожної сцени.
- Після редакційної перевірки встановіть `verified: true` для кожної сцени та `editorial_verified: true` для сюжету.
- Відредагуйте `content/subtitles.srt`. Час має вкладатися в тривалість відео, субтитри не повинні перекриватися. Сцени бажано задавати цілими секундами.

Ці прапорці фіксують рішення редактора; вони не замінюють перевірку джерел і не доводять правдивість тексту автоматично.

За замовчуванням `audio_mode: "silent"`: готове відео не міститиме аудіодоріжки. Для тихого інструментального фону виберіть `audio_mode: "music"`. Сам музичний файл зберігається окремо, не змінюється і не видаляється. Відео з медіакліпів не передає їхній оригінальний звук у результат.

`voiceover` не використовуйте: звичайний експортер відхиляє цей параметр, щоб випадково не додати голос.

## 3. Фото й відео

У сцені можна додати:

```json
"media": {
  "type": "image",
  "path": "assets/media/photo.png",
  "credit": "Автор / джерело",
  "rights_confirmed": true,
  "archive": false
}
```

Для відео: `"type": "video"`, шлях до MP4, початок кліпу `"in": 0`. Тривалість вихідного відео від цієї точки повинна покривати сцену: автоматичного повторювання документальних кадрів немає. Архівний матеріал позначається `"archive": true`, у кадрі з’являється напис «АРХІВ».

Фото та відео пропорційно вписуються цілком у виділений блок. Обличчя та об’єкти не обрізаються. Перевірка прав і правильності дати/місця зйомки залишається редакційним обов’язком.

## 4. Великі цифри, діаграми та карти

У сцені вибирайте один варіант: `media` або `graphic`.

Великий показник:

```json
"graphic": {"type": "metric", "value": "ПЕРЕВІРЕНЕ ЗНАЧЕННЯ", "label": "Що саме вимірює показник"}
```

Діаграма — від одного до чотирьох невід’ємних значень. Дані в прикладі нижче — лише синтаксис, їх потрібно замінити:

```json
"graphic": {"type": "bars", "unit": "", "items": [{"label": "Назва показника", "value": 0}]}
```

Карта — ваш перевірений GeoJSON (Polygon/MultiPolygon), межі `[west,south,east,north]`, необов’язкові маркери `lon`, `lat`, `label`:

```json
"graphic": {
  "type": "map",
  "geojson": "assets/media/verified-map.geojson",
  "bounds": [0, 0, 10, 10],
  "markers": []
}
```

Числа меж — технічний приклад, не географічна основа новини. Реальних карт або статистики без ваших перевірених файлів шаблон не підставляє. Проєкція схематична, з локальним масштабуванням довготи за середньою широтою. Не використовуйте для навігації або юридичного визначення кордонів.

## 5. Перевірка та експорт

Потрібні Python 3, FFmpeg/ffprobe, Pillow та DejaVu Sans (за замовчуванням `/usr/share/fonts/truetype/dejavu`; змініть `FONT_DIR` для іншої системи).

```sh
cd /workspace/news-social-template
python src/render.py --check-assets
python src/render.py --config content/story.json --check
python src/render.py --config content/story.json --output out/news.mp4
```

Для перегляду композиції без оригіналів плашок та без публікаційної верифікації:

```sh
python src/render.py --preview --output out/template-preview.mp4
```

Цей режим завжди додає напис «ТЕХНІЧНИЙ ПЕРЕГЛЯД • НЕ ДЛЯ ПУБЛІКАЦІЇ». Публікаційний режим `--preview` не використовує.

Поруч із результатом записуються JSON-звіти перевірки та фактична команда FFmpeg. Експорт зупиняється, якщо немає оригінальної плашки, не підтверджені матеріали, титри надто довгі, немає потрібного медіафайлу або порушені часові інтервали SRT.

## 6. Власна озвучка пізніше

Імпортуйте MP4, окремий `music.wav` та власний запис голосу у ваш відеоредактор. Це дозволяє окремо регулювати голос і музику. Рекомендований вихідний файл для цього — відео з `audio_mode: "silent"`.

Якщо потрібно лише приєднати ваш готовий запис через FFmpeg, без повторного рендерингу відео:

```sh
python src/add_voice_later.py --video out/news.mp4 --voice /path/to/your-recording.wav --output out/news-with-my-voice.mp4
```

Ця окрема команда не виконується автоматично. Вона копіює відеопотік і додає наданий вами запис; попередня аудіодоріжка замінюється, музика окремо не мікшується. Для голосу разом із музикою використайте окремі доріжки у вашому редакторі.
